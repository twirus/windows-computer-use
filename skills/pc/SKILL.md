# `/pc` — Прямое управление Windows (без субагента)

Выполни задачу пользователя на компьютере **напрямую в этом чате** через MCP-сервер `windows-desktop` (не запуская субагента):
1. Следуй правилам скилла `windows-computer-use` (`window_action`, `desktop_state`, `click_element`, `type_into_element`).
2. Объединяй цепочки из 2+ предсказуемых шагов в один вызов `batch_actions` для максимальной скорости.
3. Не закрывай приложения и вкладки пользователя без явной просьбы.
4. В конце обязательно скрой оверлей (`hideOverlayAfter: true` или `set_overlay(visible: false)`).
